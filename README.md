# Exploratory Data Analysis Concepts

A learning repository organized around common Python data-analysis libraries. The folders group examples and practice material for NumPy, pandas, Matplotlib, and Seaborn.

## Repository Structure

- `numpy/` — NumPy learning examples.
- `pandas/` — pandas examples for tabular data manipulation.
- `matplotlib/` — Matplotlib visualization examples.
- `seaborn/` — Seaborn statistical visualization examples.
- `dataset/` — datasets used by exercises, where included.

## Requirements

- Python 3
- Jupyter Notebook or another Python editor
- NumPy, pandas, Matplotlib, and Seaborn as needed by the examples

Install the commonly used packages with:

```bash
python -m pip install numpy pandas matplotlib seaborn jupyter
```

## How to Use

1. Clone or download the repository.
2. Install the dependencies used by the example you want to run.
3. Open the relevant Python file or notebook in the corresponding library folder.
4. Run examples one at a time and inspect the outputs.

## Learning Goals

The folder organization supports practice with array operations, tabular data analysis, and plotting. The exact topics and datasets vary by the files in each folder.
